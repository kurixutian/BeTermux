# Phase 2 Diff — Editor-Style Input

Phase 2 replaces blind raw-terminal typing with a Warp-style two-row input bar, full-width floating command editor, scrollable prompt context chips, persisted top/bottom positioning, durable per-session draft storage across process death, and Amendment A3's draft-on-session-close confirmation dialog.

## Added Files

- [`InputDraftStore.kt`](file:///data/data/com.termux/files/home/projects/BeTermux/app/src/main/java/com/newtermux/input/InputDraftStore.kt): persistent `SharedPreferences` draft repository keyed by runtime session handle and tab slot index so drafts survive dismissal, rotation, and OS process death; includes `saveDraftAsSnippet` helper writing unique `/draft*` triggers to `TextExpansionStore`.
- [`PromptContextResolver.kt`](file:///data/data/com.termux/files/home/projects/BeTermux/app/src/main/java/com/newtermux/input/PromptContextResolver.kt): event-driven context resolver reading `user@host`, shortened CWD, `.git/HEAD` branch/SHA, and local toolchain hints (`gradle`, `node`, `rust`, `python`) on background IO without polling.
- [`ContextChipsRow.kt`](file:///data/data/com.termux/files/home/projects/BeTermux/app/src/main/java/com/newtermux/input/ContextChipsRow.kt): horizontally scrollable tappable chips (`CWD`, `Git branch`, `last exit`, toolchain hints, `Workflows`, `ls -la`) with contextual action menus.
- [`TwoRowInputBar.kt`](file:///data/data/com.termux/files/home/projects/BeTermux/app/src/main/java/com/newtermux/input/TwoRowInputBar.kt): flat charcoal two-row docked input bar (Row 1: `user@host` + scrollable chips; Row 2: tappable draft preview field + Clear/Workflows + Send/Return).
- [`FloatingEditLayer.kt`](file:///data/data/com.termux/files/home/projects/BeTermux/app/src/main/java/com/newtermux/input/FloatingEditLayer.kt): portrait/landscape-adaptive floating multi-line command sheet with free cursor placement, soft wrapping, `Shift+Enter` newline insertion, `↵ Newline` chip, Top/Bottom dock toggle, Back/scrim dismissal preserving drafts, and Send dispatch.
- [`InputHostBridge.kt`](file:///data/data/com.termux/files/home/projects/BeTermux/app/src/main/java/com/newtermux/input/InputHostBridge.kt): lifecycle-aware bridge attaching `TwoRowInputBar` to `@+id/input_bar_top_container` / `@+id/input_bar_bottom_container`, `FloatingEditLayer` to `@+id/floating_edit_overlay`, hiding bars on overlay tabs, and flushing drafts in `onPause`.
- [`InputDraftAndLayerTest.kt`](file:///data/data/com.termux/files/home/projects/BeTermux/app/src/test/java/com/newtermux/input/InputDraftAndLayerTest.kt): unit and Robolectric Compose UI verification of process-death draft recovery, A3 snippet saving, git/project context detection, Top/Bottom persistence, landscape `FloatingEditLayer` multi-line editing, draft retention on close, and Send dispatch.
