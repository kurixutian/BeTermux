# Phase 5 Diff — Inline AI Assistant Loop (Amendments A2 & A4)

Phase 5 integrates a provider-agnostic AI assistant directly into the block flow with no separate chat tab, clear disabled/unconfigured states, zero automatic retries, cancel-on-new single in-flight concurrency, secret redaction, non-executing Accept/Edit draft insertion, and screen-reader accessibility announcements.

## Added Files

- [`AiModels.kt`](file:///data/data/com.termux/files/home/projects/BeTermux/app/src/main/java/com/newtermux/ai/AiModels.kt): defines `AiProviderKind` (`OPENAI_COMPATIBLE`, `ANTHROPIC`, `GEMINI`), `AiAction` (`EXPLAIN_ERROR`, `PROPOSE_FIX`), `AiConfig`, `AiBlockContext`, `AiRequest`, `AiResponse`, and sealed `AiSuggestionState` (`Loading`, `DisabledOrUnconfigured`, `Error`, `Ready`).
- [`AiKeyStore.kt`](file:///data/data/com.termux/files/home/projects/BeTermux/app/src/main/java/com/newtermux/ai/AiKeyStore.kt): encrypted per-provider API key storage (`api_key_${provider.id}`) backed by `AndroidKeyStore` AES-GCM on API 23+ with fallback handling when KeyStore is unavailable, plus `hasApiKey` and `maskedKeyHint`.
- [`AiContextBuilder.kt`](file:///data/data/com.termux/files/home/projects/BeTermux/app/src/main/java/com/newtermux/ai/AiContextBuilder.kt): builds `AiBlockContext` from a `TerminalBlock` and `TerminalBuffer`, trimming output to `DEFAULT_MAX_OUTPUT_CHARS` (`6000`) and running `redactSecrets` on command and output tail.
- [`AiProviders.kt`](file:///data/data/com.termux/files/home/projects/BeTermux/app/src/main/java/com/newtermux/ai/AiProviders.kt): defines `CancellableAiCall`, `AiTransport`, `AiPromptFormatter`, `AiResponseParser.parseProviderBody`, and `OkHttpAiTransport` configured with `retryOnConnectionFailure(false)` across OpenAI-compatible, Anthropic, and Gemini endpoints.
- [`InlineAiController.kt`](file:///data/data/com.termux/files/home/projects/BeTermux/app/src/main/java/com/newtermux/ai/InlineAiController.kt): enforces Amendment A2 guardrails (`max = 1` concurrent request via cancel-on-new and `inFlightCount`, `0` automatic retries with manual `retryBlock`, and clamped `maxTokens`), plus disabled/unconfigured offline state.
- [`AiSuggestionBlock.kt`](file:///data/data/com.termux/files/home/projects/BeTermux/app/src/main/java/com/newtermux/ai/AiSuggestionBlock.kt): renders the inline Warp suggestion card beneath a `TerminalBlock` with `LiveRegionMode.Polite` + `View.announceForAccessibility` + optional `onAccessibilityAnnouncement` hook (Amendment A4), and `Accept` / `Edit` / `Dismiss` / `Retry` / `Cancel` / `Open AI Settings` controls using `.semantics(mergeDescendants = true)` so workspace focus click wrappers do not merge away the card.
- [`AiHostBridge.kt`](file:///data/data/com.termux/files/home/projects/BeTermux/app/src/main/java/com/newtermux/ai/AiHostBridge.kt): bridges `InlineAiController` to `BlockHostBridge.setAiIntegration`, inserts accepted/edited commands into `InputHostBridge.insertIntoActiveDraft` (`openEditorAfter = false` for Accept, `true` for Edit) without ever writing directly to a PTY, and opens `SettingsActivity` routed to `ROUTE_AI_ASSISTANT`.
- [`AiControllerAndContextTest.kt`](file:///data/data/com.termux/files/home/projects/BeTermux/app/src/test/java/com/newtermux/ai/AiControllerAndContextTest.kt): unit and Compose Robolectric UI tests verifying bounded secret redaction, cancel-on-new / 0-auto-retry / configurable `maxTokens` / disabled state, multi-provider formatting and response parsing, and inline card rendering with `LiveRegionMode.Polite` + `InputDraftStore` draft-only insertion.
